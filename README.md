# 지구마켓 (G9 Market) 쇼핑몰 디자인

카페24 쇼핑몰 `g9market1.cafe24.com`의 새 디자인 코드를 보관하는 저장소입니다.

## 파일

| 파일 | 카페24 위치 | 내용 |
| --- | --- | --- |
| `skin/index.html` | 새 디자인의 `/index.html` (메인화면) | 메인 화면 전체 (헤더·히어로·순환 단계·구하기·등급·써클·품목표·푸터) |
| `skin/layout.html` | 새 디자인의 `/layout/basic/layout.html` (공통 레이아웃) | 메인 외 모든 페이지에 새 머리말 적용. 기존 모아스튜디오 머리말은 CSS로 숨기고 스크립트 호환을 위해 그대로 둠 |
| `skin/layout_header.html` | (layout.html 안에 포함) | 새 공통 머리말 부분만 따로 보관 |
| `skin/layout_original.html` | — | 바꾸기 전 원래 공통 레이아웃 (되돌릴 때 사용) |

꼬리말(푸터)은 기존 것을 유지합니다. 사업자 정보가 카페24 '내 쇼핑몰 정보' 설정과 자동 연동되기 때문입니다.

## 적용 방법

1. 카페24 관리자 → 디자인 → 디자인 보관함에서 현재 디자인을 복사해 새 디자인을 만든다.
2. 새 디자인의 편집창에서 `메인화면(index.html)`을 열고 `skin/index.html` 내용으로 교체 후 저장한다.
3. 미리보기로 확인한 뒤 대표 디자인으로 설정한다.

## 아직 채워야 할 빈칸

- 등급별 기준 점수, 품목별 포인트
- 구하기 카드의 첫 사연 (농가 · 재고 · 셀러)
- 사업자등록번호, 통신판매업 신고번호
- "재활용품 보내기" 버튼 링크 (수거 신청 상품 등록 후 상품 주소로 교체)
