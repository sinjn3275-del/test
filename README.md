# 입고수 (If고수) — 모의투자 시안

"입으로만 고수인지, 진짜 고수인지" 수익률로 검증하는 모의투자 서비스의 1단계 시안입니다.

## 실행

`index.html` 하나로 동작합니다. 브라우저로 열면 됩니다. GitHub Pages를 켜면 링크로 공유할 수도 있어요.

## 시안에 들어간 기능

- 닉네임 로그인, 가입 시 모의투자금 1억 원 지급
- 코인 10종 시세 (업비트 공개 API, 연결 실패 시 시뮬레이션 시세로 대체하고 화면에 표시)
- 매수·매도 (수수료 0.05%, 최소 주문 5,000원)
- 총 자산, 수익률, 평가손익, 자산 추이 그래프, 최대 낙폭(MDD)
- 거래 내역 (추가만 가능하고 수정·삭제 불가)
- 랭킹 (수익률, MDD, 승률, 거래 횟수)

## 시안의 한계 (다음 단계에서 해결)

- 계정과 거래 기록이 브라우저(localStorage)에만 저장됨 → 서버 DB와 소셜 로그인으로 교체
- 랭킹은 같은 기기의 계정끼리만 비교, "예시" 계정은 설명용 가상 계정
- 주문은 주문 시점 시세로 즉시 체결 → 정식 버전에서는 다음 시세로 체결해 지연 시세 악용 방지
- 국내 주식, 해외 주식, 금·유가, 인증 고수, 시즌제 미포함

모의투자 서비스이며 투자 권유가 아닙니다.
